How the numbers are defined

  • Each Alpha row holds straw yellow Gasoline, golden amber Diesel and pale blue Ethanol. Suitability depends on the selected car. A collected row counts once, even if more than one can is taken.
  • A pickup opportunity is the first forward pass of a row with room in the bag and an available cube at the approach gate, or a pass on which fuel was collected. Full or empty rows without a collection are excluded.
  • Collection rate = rows where the player picked up a cube ÷ pickup opportunities. A colour's share uses the first collected fuel in each eligible row; the shares add up to the total. Pickups collected also includes pickups before a row's exit gate is reached.
  • For the A/B test each race uses a lane spacing (the gap between cube centres) picked at random, so rates can be compared across spacings.
  • Races played in the Unity editor are hidden unless "Include editor test sessions" is ticked.
Data is collected by FuelPickupAnalytics.cs in the game and stored in Google Sheets through Analytics/google-apps-script/Code.gs. This page recomputes everything each time it loads.
